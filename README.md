# QazaqGaz & Intergas Central Asia · 3D-мониторинг демонтажа кабеля МКСБ 4×4×1.2

Интерактивное веб-приложение для производственного мониторинга и 3D-инспекции хода демонтажа кабельной линии связи КЛС-254 (кабель связи МКСБ 4×4×1,2 в двухниточном исполнении) на участке 880–1134 км магистрального газопровода «Средняя Азия – Центр» (МГ САЦ-4, Джангалинское ЛПУ).

## 🚀 Возможности
- **Светлая тема по умолчанию в стиле Apple Liquid Glass / visionOS**: кристальная четкость шрифтов, контрастные даты и цифры, полупрозрачные стеклянные карточки с мягкими тенями.
- **Интерактивные иконки**: переключение темы кнопкой Солнца ☀️ ↔ Луны 🌙 с плавной анимацией морфинга; иконки камер (Изо, Срез, Профиль, Сверху) и инструментов 3D (Взрыв-схема, Изгиб R≥15D, Облет 360°, Рентген).
- **Хромированный логотип**: стилизованный металлический герб Интергаз Центральная Азия с переливом хрома.
- **3D-модель кабеля МКСБ 4×4×1.2**: 90 единиц длины, послойный ступенчатый срез по ГОСТ 15125-92 (16 медных жил 1.2 мм, полистирол, кабельная бумага, свинец С2/С3, битум, стальная ленточная броня Б) без наложения граней и мерцания.
- **Реалистичная 3D-траншея 1.2 м в грунте**: трапецеидальный профиль откосов 1:0.5 по СНиП, песчаная подушка 100 мм, 2 параллельные нитки кабеля с межосевым зазором 100 мм, желтая сигнальная лента и плавающие CAD-выноски размеров.
- **Графика и линейный профиль 10 км**: детальный график суточной выработки за ноябрь 2026 г., интерактивные пикеты (ПК 981,0 – ПК 966,86) с фиксацией достижения контрольного репера 10.00 км.
- **Оценка извлеченных металлов**: сводка по меди (Cu ~4.53 т), свинцу (Pb ~34.01 т), бронеленте (Fe ~17.00 т).
